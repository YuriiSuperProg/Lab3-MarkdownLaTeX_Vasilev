### Markdown-элементы
#### 1. Заголовки

В Markdown заголовки создаются с помощью символа #. Количество # определяет уровень заголовка.

# H1 - Заголовок первого уровня
## H2 - Заголовок второго уровня
### H3 - Заголовок третьего уровня
***
#### 2. Форматирование текста
* **Полужирный текст** - `**текст**`
* *Курсив* - `*текст*` 
* ***Полужирный курсив*** - `***текст***`
* ~~Зачеркнутый текст~~ - `~~текст~~`
* `Код в линию` - `код`
* Блок кода на языке программирования
```python
print("Hello world!")
```
***
#### 3. Списки
**Маркированный список**
* Первый пункт
* Второй пункт
* Третий пункт

**Нумерованный список**
1. Первый пункт
2. Второй пункт
3. Третий Пункт

**Вложенный список**
1. Основной пункт
    1.1 Подпункт
    1.2 Подпункт
2 Второй основной пунк
    2.1 Подпункт
    2.2 Подпункт

### LaTeX в Markdown

#### Inline-формула
Площадь круга вычисляется по формуле $S = \pi r^2$
Формула Эйнштейна: $ E = mc^2$

#### Блочная формула

$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$

#### Дополнительные конструкции
* Дробь: $\frac{a}{b}$
* Корень: $\sqrt{x}$, $\sqrt{y^4}$
*  Груческие буквы: 
* $\alpha, \beta, \gamma, \lambda$
* Степень: $x^2, x^{10}$
* Индекс: $a_i, a_{i+1}$
* Матрица: 
$$
\begin{pmatrix}
1 & 2 \\
3 & 4
\end{pmatrix}
$$
