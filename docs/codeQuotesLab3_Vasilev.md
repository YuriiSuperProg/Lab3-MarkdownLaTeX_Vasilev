2. *Код на **Python**:*
```python
// Добавление чисел в список
a = []
n = int(input("Введите любое число: "))
for i in range(1, n + 1):
    a.append(i)
print(a)
// При n = 5
// Вывод будет: [1, 2, 3, 4, 5] 

```

```

for(int i = 1; i < n; i++){
    a.Add(i);
}
Console.WriteLine("[" + string.Join(", ", a) + "]");
// При n = 5
// Вывод будет: [1, 2, 3, 4, 5]
```
