## Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта

#### Markdown — это облегчённый язык разметки, созданный для форматирования текста с помощью простых символов и знаков препинания

#### Где применяют Markdown
* Написание технической документации и файлов README на GitHub.
* Оформление постов, статей и комментариев на форумах и в блогах (например, Reddit, Stack Overflow).
* Создание личных заметок в приложениях вроде Obsidian.

#### Разработчики используют Markdown для быстрого создания читаемой документации, которая хранится прямо вместе с кодом. Вместо того чтобы тратить время на сложное оформление в Word или написание HTML-тегов, программист может за пару минут оформить понятную инструкцию, не отвлекаясь от написания кода.
